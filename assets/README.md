# Assets

This folder contains image and printable assets used by the Entangled Cat project.

## Contents

- `logo-entangled-cat.png` — Project logo image.
- `card_templates/` — Design templates and source files for card printing.
- `printable/` — Pre-made printable exports and instructions.

## Usage

- Use `logo-entangled-cat.png` for README or branding.
- Use files from `card_templates/` when designing or exporting new cards.
- Use `printable/` to access ready-to-print versions of cards or game materials.
