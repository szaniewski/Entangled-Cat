# Contributing to Entangled Cat

Thank you for your interest in contributing to Entangled Cat.

## How to contribute

- Open issues for bugs, balance suggestions, or new card ideas.
- Submit pull requests with clear descriptions.
- Keep card data in `game/cards/` and documentation in `docs/`.

## Development checklist

- Add or update YAML files for cards.
- Add or improve rules or algorithm documentation.
- Run simulations in `simulator/` before submitting balance changes.
