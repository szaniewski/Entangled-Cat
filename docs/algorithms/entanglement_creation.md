# Entanglement Creation

Points: 10
Deck Count: 4

Required Gates: H, CNOT

Description: Creates entangled qubits via a Hadamard gate followed by a controlled-NOT.

Educational Notes:
- Entanglement Creation prepares a Bell pair that can be used for teleportation and dense coding.
- The sequencing of H then CNOT is a classic two-qubit entangling pattern.
