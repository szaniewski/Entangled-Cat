# Superdense Coding

Points: 20
Deck Count: 3

Required Gates: H, CNOT, CX or CZ, MZ

Description: Encodes two classical bits into one qubit using entanglement and corrections.

Educational Notes:
- Superdense Coding uses an entangled pair to send extra classical information.
- Classical corrections (CX or CZ) restore the encoded state after measurement.
